BT Transceiver
==============

BT Transceiverは、Android端末同士で音声通話とテキストチャットを行うトランシーバーアプリです。

Wi-Fi、Wi-Fi Direct、Bluetooth Classicを切り替えて使えます。画面はトランシーバーの液晶風UIで、PushTalk通話、チャット、受信メーター、通信状態表示をひとつのアプリ内で扱えます。

主なできること
--------------

- `PUSH TALK`を押している間だけ話す半二重通話
- `HALF DUPLEX` / `FULL DUPLEX` の切り替え
- Wi-Fi、Wi-Fi Direct、Bluetooth Classicの通信方式切り替え
- 音声通話と同じ通信経路で送るテキストチャット
- チャット送信の到達確認表示
- 受信音量に合わせて動くアナログメーター
- 送受信bitrateの表示
- Wi-Fi RSSI、Wi-Fi Direct RSSI、Bluetooth RSSIの目安表示
- PTT開始時のビープ音、終了時のアナログトランシーバー風ノイズ
- 接続履歴の保存
- 前回接続したBluetooth端末、Wi-Fi Direct端末への自動再接続
- 無通信状態が続いた場合の自動切断
- バックグラウンド移行時の通信維持

画面構成
--------

画面上部には共通メニューがあります。

- `WIFI`: 同じWi-Fi LAN上の端末と通信します。
- `WIFIDIRECT`: Wi-Fi Directで近くの端末と直接接続します。
- `Bluetooth`: Androidでペアリング済みの端末と接続します。

共通メニューには、現在の接続状態、接続先、通信モード、RSSI、bitrateも表示されます。

画面下部にはタブがあります。

- `PushTalk`: 音声通話、通話方式切替、メーター、接続先一覧を表示します。
- `Chat`: テキストチャットを表示します。

はじめて使う
------------

1. 2台のAndroid端末にアプリを入れます。
2. 両方の端末でアプリを起動します。
3. マイク、Bluetooth、Wi-Fi Direct、通知などの権限を求められたら許可します。
4. 使いたい通信方式を画面上部から選びます。
5. 接続が完了したら、`PushTalk` または `Chat` タブで通話・チャットを開始します。

Wi-Fiで使う
-----------

Wi-Fi版は、2台の端末が同じWi-Fi LANに接続されている場合に使います。

1. 両方の端末を同じWi-Fiに接続します。
2. 両方の端末で画面上部の `WIFI` を選びます。
3. 接続状態が待機中になったら、`PushTalk` タブで `PUSH TALK` を押して話します。
4. `Chat` タブではメッセージを入力して `SEND` を押します。

Wi-Fi版では、表示されるRSSIは端末とアクセスポイント間の電波強度です。相手端末との直接RSSIではありません。

Wi-Fi Directで使う
------------------

Wi-Fi Direct版は、Wi-Fiルーターを使わず端末同士を直接接続したい場合に使います。

1. 両方の端末で画面上部の `WIFIDIRECT` を選びます。
2. 近くの端末が一覧に表示されるまで待ちます。
3. 片方の端末で相手端末を選びます。
4. 接続状態が `リンク確立` になったら通話・チャットが使えます。

一度接続したWi-Fi Direct端末は記録されます。次回以降、前回の相手が探索結果に見えた場合は自動接続を試みます。

Wi-Fi DirectのRSSIは、端末やAndroid実装によって取得できない場合があります。取得できる端末では `DIRECT RSSI` としてdBm表示されます。

Bluetoothで使う
---------------

Bluetooth版は、Androidでペアリング済みの端末と接続します。

1. Androidの設定画面で、相手端末とBluetoothペアリングします。
2. 両方の端末でアプリを起動します。
3. 画面上部の `Bluetooth` を選びます。
4. `PushTalk` タブの端末一覧から相手端末を選びます。
5. 接続状態が `リンク確立` になったら通話・チャットが使えます。

Bluetooth Classicを使うため、基本的には事前ペアリングが必要です。

音声通話
--------

`PushTalk` タブで操作します。

- `PUSH TALK` を押している間だけ音声を送信します。
- ボタンを離すと送信を終了します。
- 送信開始時はビープ音が鳴ります。
- 送信終了時はアナログトランシーバー風のクリックノイズが鳴ります。
- これらの効果音は相手側にも音声として送信されます。

`HALF DUPLEX` は通常のトランシーバー方式です。話している間は主に送信側になります。

`FULL DUPLEX` に切り替えると、マイクを継続的に有効にして双方向通話に近い使い方ができます。通信状態や端末性能によっては音の回り込みや遅延が出る場合があります。

チャット
--------

`Chat` タブで操作します。

1. 入力欄にメッセージを書きます。
2. `SEND` を押します。
3. 自分の送信メッセージは右側の吹き出しに表示されます。
4. 相手からのメッセージは左側の吹き出しに表示されます。

送信直後は吹き出しに `送信中` と表示されます。相手端末がメッセージを受信してACKを返すと、表示が `届きました` に変わります。

通信が切れている場合や送信に失敗した場合は、システムメッセージまたは `未達` として表示されます。

表示の見方
----------

- `待機中`: 通信できる状態で待機しています。
- `リンク確立`: 相手端末との接続ができています。
- `送信中`: 音声を送信しています。
- `受信中`: 相手から音声を受信しています。画面はオレンジ表示になります。
- `BITRATE TX/RX`: 直近の送信・受信データ量をkbpsで表示します。
- `SIGNAL`: RSSIなどの電波強度の目安を表示します。
- アナログメーター: 受信音声の大きさに合わせて針が動きます。

接続履歴と自動再接続
--------------------

接続した相手は履歴に保存されます。

Bluetoothでは、最後に接続したペア済み端末へ自動再接続を試みます。

Wi-Fi Directでは、前回接続した相手が探索結果に表示された場合、自動接続を試みます。

自動切断
--------

音声またはチャットの通信が一定時間ない場合、アプリは通信を自動切断します。

Wi-Fi Directでは、切断時や別モードへの切り替え時にWi-Fi Directグループを解除します。これにより、Wi-Fi Directが起動したまま残りにくくなります。

うまくつながらないとき
----------------------

- 両方の端末で同じ通信方式を選んでください。
- Wi-Fi版は、両方の端末が同じWi-Fiに接続されているか確認してください。
- Wi-Fi Direct版は、両方の端末で `WIFIDIRECT` を選び、相手が一覧に出るまで少し待ってください。
- Bluetooth版は、Android設定で事前にペアリングされているか確認してください。
- マイク、Bluetooth、Wi-Fi Direct、通知の権限を許可してください。
- つながらない場合は、いったん別モードに切り替えてから戻すか、アプリを再起動してください。
- チャットが `送信中` のままの場合、相手端末が受信できていない可能性があります。接続状態を確認してください。

注意事項
--------

- Bluetooth Classicの安定接続にはペアリングが必要です。
- RSSI表示は目安です。端末やAndroidバージョンによって取得できない場合があります。
- Wi-Fi Directの直接RSSIは、端末実装によって表示できない場合があります。
- FULL DUPLEXは端末のスピーカー音をマイクが拾うとハウリングする場合があります。
- 商用リリース時は、実機で複数端末・複数Androidバージョンの通信テストを行ってください。
